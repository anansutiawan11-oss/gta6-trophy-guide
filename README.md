FIFTY-FIVE is an offline web guide and tracker for all 55 PlayStation 5 trophies in Grand Theft Auto VI: official trophy names, descriptions and grades, a cited guide for every trophy, a checklist saved in the browser with export/import, kind and grade filters, a spoiler shield, a three-stage platinum roadmap, missable and unconfirmed flags, and five disputes shown with both sides — all static files that run with no network.

## Run it

```sh
node serve.ts
open http://localhost:8080
```

Open `?demo=1` to preview with 10 trophies earned, `?spoiler=on` to hide hidden story trophies, `?view=roadmap` for the roadmap, and `?trophy=28` to open one trophy's guide directly.

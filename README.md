FIFTY-FIVE is an offline web guide and tracker for all 55 PlayStation 5 trophies in Grand Theft Auto VI: the official names, descriptions and grades, a step-by-step guide for every trophy with cited sources, a checklist saved in the browser with JSON export and import, filters, a spoiler shield for hidden story trophies, a three-stage platinum roadmap, and missable and unconfirmed flags plus a page of disputes where the guides disagree — all as static files that run with no network.

## Run it

```
node serve.ts
open http://localhost:8080
```

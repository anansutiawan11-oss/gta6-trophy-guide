FIFTY-FIVE is an offline web guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words with cited sources, a checklist saved in the browser with export and import, filters by kind, a spoiler shield that hides hidden story trophies until earned, a three-stage platinum roadmap, missable and unconfirmed flags, and a disputes section where the sources disagree — all as static files that work with the network off.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

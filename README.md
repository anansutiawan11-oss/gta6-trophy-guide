FIFTY-FIVE is an offline web guide and tracker for all 55 PlayStation 5 trophies in Grand Theft Auto VI: official names, descriptions and grades, a cited guide for every trophy, a checklist saved in the browser with export and import, filters, a spoiler shield, a three-stage platinum roadmap, and missable and unconfirmed flags plus the disputes where launch-week sources disagree — all as plain static files that run with no network.

## Run it

```sh
node serve.ts
open http://localhost:8080
```
